# SudoZen Privacy Policy site

Static GitHub Pages site for the SudoZen privacy policy (English and Turkish).

- `index.html` – both languages, generated by `tool/build_privacy_site.py` from the markdown files
- `privacy-policy-en.md`, `privacy-policy-tr.md` – sources
- `assets/privacy-style.css`

Published at https://omer-poyraz.github.io/sudozen-privacy-policy/ (GitHub Pages, branch `main`, root).

Contact: https://github.com/omer-poyraz/sudozen-privacy-policy/issues
